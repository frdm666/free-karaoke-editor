KARAOKE FROM A SONG AND ITS LYRICS
Version 4.47.0


WHAT YOU NEED
=============

Python 3.8 or newer — download it from https://python.org
During the installation BE SURE to tick "Add Python to PATH".

Nothing else has to be installed by hand.


1. INSTALLING (once)
====================

Double-click:   Install.bat
                (on macOS: install.command)

It asks, in order:

  1. ffmpeg      required          -> press Enter, it installs itself
  2. stable-ts   accurate timing   -> 1-2 GB, Enter = "no"
  3. demucs      the instrumental  -> 1-2 GB, Enter = "no"
                 (soundfile comes with it — without soundfile the
                  instrumental is computed and then fails on writing)
  4. pillow      video for YouTube -> small, press Enter
  5. numpy       speed-up          -> small, press Enter

Without stable-ts and demucs the program still works, but the timing is
approximate and there is no instrumental. They can be added at any time.


ON macOS: "THE FILE CANNOT BE CHECKED FOR MALWARE"
==================================================

That is what the first double-click on install.command or studio.command
gets. Nothing was scanned and nothing was found: a file downloaded from
the internet carries a mark, and these scripts are not signed by a paid
Apple developer account. Inside each is twenty lines of readable text.

Any one of these is enough:

  1. Start it from the Terminal — the mark stops double-clicks, not
     commands:

         cd ~/Downloads/karaoke
         python3 app/studio.py

     (type "cd " and drag the folder into the Terminal window)

  2. Let the file through once: System Settings -> Privacy & Security ->
     scroll down to the blocked file -> "Open Anyway".
     On macOS 14 and older: Control-click the file -> Open -> Open.

  3. Take the mark off the folder, and put back the right to run that
     unpacking with Finder often drops:

         xattr -dr com.apple.quarantine ~/Downloads/karaoke
         chmod +x ~/Downloads/karaoke/*.command

Taking the repository with "git clone" instead of a ZIP avoids all of
this: files that arrive through git are never marked.


UPDATING
========

Taken with "git clone" once, the program updates with one command:

    cd ~/Documents/karaoke
    git pull

Your songs and your settings are not touched by it: projects\ and
app\settings.ini are not in the repository at all, so an update
replaces the program and the documentation and leaves those alone.

Already have songs in a folder that came from a ZIP? Clone next to it
and carry the two things across:

    cp -R ~/Downloads/karaoke/projects/. ~/Documents/karaoke/projects/
    cp ~/Downloads/karaoke/app/settings.ini ~/Documents/karaoke/app/

If "git pull" refuses because a file of the program was edited:
"git checkout -- <file>" puts that one back, "git reset --hard
origin/main" puts them all back. Songs and settings live outside the
repository and are not affected.

When an update brings something new to install - yt-dlp for links did -
run the setup once more. It skips whatever is already there.


2. THE LYRICS FILE
==================

An ordinary .txt. One line of the song = one line of the file.
IMPORTANT: write repeats out as many times as they are sung.

    title: The title
    artist: The artist

    [Verse]
    the first line
    the second line

The header and [Verse] are optional. A line in SQUARE brackets is a
section label, it is not sung.

A line in ROUND brackets is an ordinary line of the song: that is how
backing vocals are written. It is sung, shown smaller and in italics, and
is counted as the SECOND voice right away (which has its own colour). The
exception is section names: (Chorus), (Chorus 2) and the like.

WHO SINGS, AND HOW MANY TIMES — can be set right in the text:

    This line is sung by the first voice
    2: and this one by the second

    [voice 2]
    everything from here in the second,
    [voice 1]
    and here in the first again.

    Chorus x4        <- the line unfolds into four repeats

It understands x4, ×4 and the Cyrillic х4, in brackets too: (x4). A number
from 2 to 99.

Punctuation standing on its own (a dash, an ellipsis) is not lost — it
sticks to the neighbouring word and stays on the screen.

Any encoding will do, the program works it out.


3. MAKING THE KARAOKE
=====================

THE EASIEST WAY IS THE STUDIO.

Run:  Studio.bat

The program window opens.

DRAG THE SONG AND THE LYRICS RIGHT INTO THAT WINDOW — both files at once.

OR PASTE A LINK. Under the song field there is a field for a link to a
video: press "Take the sound" and the audio is pulled out of it. That
needs yt-dlp (Install.bat offers it, or: pip install yt-dlp). If the
download fails, the reason is shown and another link can be tried.

THE WORDS CAN COME THREE WAYS. A file, as always. Or the text found by
the name of the song right after the download — read it first, it is a
suggestion and it can be wrong. Or "Paste the text": type or paste the
words into the box and press "Use this text".

As soon as both files are picked, a REPORT appears: the length, the tempo,
how many lines and words, which language, what the program is going to do
and roughly how long it will take. If the lyrics are not from this song, it
notices.

Before building you can choose the language of the song — it sits next to
the model. By default the language is detected from the text itself and is
named in the log. For a song in another language this matters: with the
wrong language the timing drifts.

Wait for the build and you land in the editor.

Do not feel like dragging — the "Add a song" button and picking the files
by hand. The browser opens where you were last time; the folders for songs
and for lyrics are remembered separately.

When you pick a model the window says whether it is already downloaded: an
absent one has to be waited for (medium is a gigabyte and a half). While a
long step runs, the log shows every 15-20 seconds that the process is alive
and how much time has passed.

In the studio:
  - edits save THEMSELVES, nothing has to be rebuilt;
  - at the bottom there is a timeline with the voice waveform: you can see
    where the singing is. The shaded places are the ones with no singing
    for a long while: the intro, an interlude, a solo. Lines should not
    land there;
  - lines on the timeline can be dragged with the mouse, they snap to the
    beginning of a phrase;
  - under them is a yellow row — the words of the selected line. By the
    middle a word moves as a whole, by the edges its length is set: inside
    a line the singing is uneven, and an even layout lies;
  - the line block has two edges too: the left one moves the start, the
    right one the end. Only the outermost word changes with it — the rest
    stay exactly where they were;
  - the note by the song title always shows whether it is saved or not;
  - SEVERAL LINES AT ONCE: press on a line and drag across its neighbours
    (or Shift+click, Ctrl+click to add one, Escape to clear). The voice,
    "the original", deleting and pasting all work on the whole batch;
  - "⧉ Copy" remembers the selection whole, "⧉ Paste line" puts the copies
    BELOW the selection without overwriting anything, and "⧉ Paste rhythm"
    lays only the word layout onto a line with the same number of words.
    Ctrl+D — a duplicate of the line under the original;
  - "◑ Voice" moves a line to the second vocal: on the timeline it goes to
    the second lane, on screen it is painted in the second colour. If two
    voices sound at the same time, the lines are split to the sides so each
    person reads their own;
  - "♪ Original" keeps the recorded voice on a line: a backing part, speech,
    a piece that matters to the story. There is no need to sing it, and that
    is visible in advance;
  - the four swatches on the timeline are the colours: the "voices" pair and
    the "background and letters" pair. Letters that blend into the
    background are fixed by the program itself;
  - on the right is the SUMMARY: the length, the share of singing, lines and
    words, the places without singing (you can click them), what the timing
    was made with, how many lines the second voice has and how many are left
    to the original;
  - while nobody sings, a countdown to the nearest line runs at the top — so
    you can see the song has not stalled. Short pauses are not counted;
  - on the right is the list of lines worth checking;
  - the "Standalone HTML" and "MP4 video" buttons — when everything is ready;
  - "Time it again" — re-reads THE SAME lyrics file from disk. Fixed the txt
    (split the lines differently, corrected words) — press this button, there
    is nothing to pick;
  - "Other lyrics" — if the new text is in a different file;
  - the cross on a song card removes it from the studio (the sources are
    intact);
  - "♪ Own backing track" — put the artist's real instrumental in place of
    the separated one. The button is at the top, next to "Time it again".
    The order is:
        1. build the song as usual (the instrumental is not required);
        2. open it in the studio;
        3. press "♪ Own backing track" and pick the file.
    The timing stays in place. If the instrumental starts elsewhere, the
    program finds the shift, moves the timing along and says by how much.

SCREAMED OR GROWLED VOCAL
  The program does not transcribe, it lays YOUR words on the audio, so an
  unintelligible vocal is not hopeless. Three things decide how well it
  goes:
    1. leave the instrumental ON — the timing is made from the separated
       voice, not from the mix;
    2. the voice is levelled before the model hears it (automatic, and it
       changes neither pitch nor time);
    3. mark the stretches with no words in them — see just below.
  Also: choose the language of the song by hand, and take a bigger model
  if the machine has the memory. Re-timing uses the model the song was
  built with and says which one that is.


PUTTING A STUBBORN SONG RIGHT
  In the editor, for the song that came out wrong in one place:
    - "✂ No words here" on the timeline: press and drag over a vocalise
      to mark it, click a mark to take it off (the field beside it is
      the same thing in numbers);
    - select the lines that went wrong and press "↻ These lines" — only
      that stretch is timed again, in seconds instead of minutes;
    - "🔒 Lock" on lines you put right by hand: re-timing leaves them;
    - "⤸ Split" cuts a line in two where the singing pauses inside it,
      "⤹ Join" puts it back with the next one — no re-timing either way;
    - on a marked stretch the ORIGINAL voice stays in the backing, so a
      vocalise is heard instead of a hole (a switch beside the marks);
    - lines drawn with a dashed border are the ones the model barely
      heard — their timing is a guess, check those first.
  And to measure rather than guess:
      python3 app/tools/bench.py song.mp3 lyrics.txt


WHERE THERE ARE NO WORDS
  A vocalise, a wordless scream, a hummed intro are all voice: nothing
  measurable tells them from a sung line, so the timing crawls onto them
  and the karaoke shows words where nobody sings. Say where they are:

    - the "Where there are no words" field, under the model and the
      language:   0:00-0:42, 3:10-3:50
    - or in the lyrics file, as a heading with a time range in it:
          [Guitar solo 3:10-3:50]
          [нет текста 1:02-1:40]
    - or in the editor, next to "Re-time", with the timeline in front of
      you: mark, press "Re-time", the words stay off.

  Those stretches are cut out of what the aligner hears, and the repairs
  treat them as silence. It says nothing about the rest of the song: it
  keeps words off the marked places, it does not promise them elsewhere.
  The marks are saved with the song.


A MISTAKE IN THE LYRICS THEMSELVES
  - a typo in a line: select the line and press "✎ Line text" (or double
    click — on the line on stage or on its block on the timeline). Fix it,
    Enter.
    The time of the line stays, the words are laid out anew. Escape cancels.
  - a forgotten line: select the one AFTER which to insert it and press
    "＋ line" — the text can be typed straight away.
  - a stray line: select it and press "－ line".

None of this needs the song rebuilt, and the timing is not lost.
Made a mistake — Ctrl+Z or the "↶ Undo" button puts it back.


Keys in the studio:
  Ctrl+Z     undo the last edit
  Space      play and pause
  Wheel      scroll the text
  Home/End   to the start and to the end of the text
  ← →        seek by 5 seconds
  ↑ ↓        select the line above or below
  [ ]        move the selected line by 50 ms
  Enter      put the selected line on the current second
  Delete     delete the selected lines
  Ctrl+C     copy the selection
  Ctrl+V     paste the rhythm into the selected line
  Ctrl+Shift+V  paste the copied lines below
  Ctrl+D     duplicate the line
  Shift+↑ ↓  extend the selection

To close the studio — close the black console window.


THE OLD WAY, WITHOUT THE WINDOW
===============================

Select the song and the lyrics with the mouse and drag both files onto:

    app\Make-karaoke.bat

Next to the song a ..._karaoke.html appears — open it with a double click.
No internet is needed, the file works on any computer.

A whole folder at once:  app\Whole-folder.bat
The files must be named alike:  Wind.mp3 + Wind.txt


4. SETTINGS
===========

The file app\settings.ini, change the values to the right of "=".
The keys are English, the Russian ones are understood too.

That file is yours: Install.bat makes it on the first run from
app\settings.example.ini and never touches it again, so an update
cannot overwrite what you chose. Without the file the defaults are used.

    align = auto        auto | whisper | energy
    model = small       tiny | base | small | medium | large-v3
    language = auto     auto | ru | uk | en | de | fr | es | it | pl …
    colors = #4de1ff,#ff8ad1      the voice colours
    theme  = #0a0b14,#e8ebf5      the background and the letters
    ui-lang = auto      the language of the labels: auto | en | ru
    instrumental = yes  yes | no

The bigger the model, the more accurate the timing and the more memory it
needs: small ~2 GB, medium ~4.5 GB, large-v3 ~8 GB. If there is less memory
than the model needs, it will not be "slower" but many times slower — the
system starts moving data to the disk. The studio writes "heavy for this
machine" next to a model when that is your case.

Installed stable-ts and demucs — leave it as it is.
Did not — write:  align = energy   and   instrumental = no


5. VIDEO FOR YOUTUBE
====================

Drag a finished ..._karaoke.html onto:

    app\Make-video.bat

An MP4 1920x1080 appears next to it, ready to upload.
It makes sense to render a 15-second sample first:

    py app\tools\video.py "file_karaoke.html" --start 45 --seconds 15

Before rendering, the video prints its own report (the song, the length, the
lines, where two sing together, the colours, the number of frames), and in
the intro and in long interludes it shows a countdown to the nearest line at
the top. The colours and the styling are taken from the page itself. When the
file is ready, the folder it is in opens.


IF THE TIMING HAS DRIFTED
=========================

The most convenient place is the Studio (see point 3).

It can be done in the standalone HTML too, where there is one main action:

  1. Click the line you need — it gets underlined and pinned: the song plays
     on while that line is still the one being edited.
     The "not this one" button next to it clears the choice.
  2. Play up to the place where it starts being sung.
  3. Press "Line starts here".

The "and all the following" checkbox moves the whole rest of the song along —
that is for when everything drifted after a solo.

Fine tuning — the [ and ] keys, 50 ms at a time.
The whole text at once is moved by the "Offset" slider.

Nothing can be ruined: "Undo" goes back one step, "Reset all" returns to the
original timing.

TO GET YOUR EDITS INTO THE VIDEO, press "Save the page with the edits" and
make the video from the saved file.


NOT ENOUGH MEMORY
=================

If "The paging file is too small", WinError 1455 or "not enough memory" flash
by in the output — the machine ran out of memory. Demucs and Whisper are
hungry: the instrumental needs about 4 GB, the small model about 2 GB.

What helps, most effective first:

  1. Increase the Windows paging file:
     Settings -> System -> About -> Advanced system settings ->
     Performance -> Settings -> Advanced -> Virtual memory -> Change.
     Choose "System managed size" or set 16384 MB by hand.
     This solves it most of the time.

  2. Close the browser and other heavy programs.

  3. Turn the instrumental off:  instrumental = no  in settings.ini

  4. Take a smaller model:  small -> base -> tiny

The program warns in advance when free memory is short.


SOMETHING IS WRONG
==================

To check a finished page and see what does not add up:

    py app\tools\diagnose.py "file_karaoke.html"

To fix the time of a line by hand:

    py app\tools\fix_line.py "timings.json" --list
    py app\tools\fix_line.py "timings.json" --line 34 --start 2:30.81

To rebuild the song with your own timings:

    py app\karaoke.py "song.mp3" "lyrics.txt" --timings "timings.json"

WHAT IS WHERE
=============

Only what is needed is in the root:

    Install.bat  install.command    install (once)
    Studio.bat   studio.command     open the window
    README.md    README.ru.md       the description
    projects\                       your songs

Everything else is inside app: settings.ini, this guide,
Make-karaoke.bat and Make-video.bat, the tests, the Dockerfile.
Song folders are named in Latin letters: “Мамины Усы” -> maminy-usy.


THE LANGUAGE OF THE WINDOW
==========================

The RU / EN button in the header of the window and on the finished page. The
choice is remembered. A new language is a file app\kstudio\messages\<code>.json,
with an example next to it: template.json. Empty values fall back to English.


IN A CONTAINER (if you would rather not install Python and the models)
======================================================================

    cd app && docker compose up --build

Then open http://127.0.0.1:8770/ — the same window. The songs stay in
projects, music for importing goes into music.
